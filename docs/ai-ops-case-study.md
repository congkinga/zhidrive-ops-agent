# 智驾运营 Agent 项目复盘

## 项目背景与问题

智驾产品运营中，NOA 体验反馈经常停留在“变道犹豫、NOA 降级、接管提醒晚”等主观描述。问题定位依赖人工归因，产品、研发、测试、硬件之间的协同成本较高，闭环不完整。

## 项目目标

- 建立场景化评测和五维归因标准。
- 将自然语言反馈转化为可派发、可验证、可复盘的运营工单。
- 降低人工归因和重复沟通成本。

## 我的角色

负责用户调研、运营指标设计、AI Agent 工作流设计、数据看板和跨团队落地。

## 执行过程

1. 调研产品、测试、研发、硬件四类用户，提炼核心痛点。
2. 设计场景评测标准和感知、决策、交互、硬件适配、场景边界五维归因模型。
3. 搭建 Agent 与 RAG 知识库，实现反馈解析、案例沉淀和指标看板。
4. 通过内容触达、活动提报和 AI 运营周报提升用户活跃度。

## 结果与复盘

- 支撑 120+ 条问题案例持续沉淀。
- 核心问题进入产品优化排期比例达到 90%。
- 人工答疑和问题归因流程得到明显简化。

不足：数据量仍较小，部分复杂场景的自动归因准确率需要持续优化。
