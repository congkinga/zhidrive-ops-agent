# 智驾产品体验运营助手

这是一个面向智能驾驶产品运营场景的 0→1 产品原型。项目把 NOA 场景评测、问题分类定级、跨部门反馈闭环和公开行业情报研究放进同一个可运行的工作流。

## 产品目标

把一个智驾体验问题从“用户说不好用”转成“可定位、可派发、可验证、可复盘”的产品运营任务。

## 当前可见能力

- 场景录入：城市道路、高速道路、变道、跟车、避障、泊车、园区、掉头、环岛
- 问题分类：感知、决策、交互、硬件适配、场景边界
- 严重度标记：S/A/B/C
- 证据链接与责任方建议
- 闭环模板：问题描述、判断依据、短期动作、验证方式、复盘结论

## 边界

- 不使用任何企业内部数据
- 不公开未确认的具体车型缺陷
- 不把公开报道中的趋势表述成内部测试结论
- 不承诺能替代真实车端日志或工程诊断
